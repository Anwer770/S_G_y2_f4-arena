```ts
// InventoryService

  return calculateStock(products, records, settings);   // ← settings قد تكون undefined
}
// stock.ts
export function calculateStock(products, records, settings: AppSettings) {
  if (settings.skipCancelled && ...)                     // ← TypeError
```

**العقد كان يكذب:** التوقيع يقول «اختياري» والجسم يقرأ منه بلا حماية. أثره العملي: أي استدعاء لـ`calculateCurrentStock()` بلا إعدادات — من اختبار أو خدمة جديدة أو مسار إقلاع — كان يُسقط الدالة بـ`TypeError: Cannot read properties of undefined (reading 'skipCancelled')`. وهذا ما أكّده أول اختبار كُتب للحالة.

**الإصلاح:** `settings?` في التوقيع، والافتراضي داخل الدالة:

```ts
const skipCancelled = settings?.skipCancelled ?? true;   // = DEFAULT_APP_SETTINGS.skipCancelled
```

`true` ليس اختياراً جديداً: هو قيمة `DEFAULT_APP_SETTINGS.skipCancelled` في التطبيق. أي أن السلوك في المسار الوحيد المستخدم (الواجهة تمرّر الإعدادات) لم يتغيّر حرفاً واحداً، وتغيّر فقط المسار الذي كان **ينفجر**.
