## 2. العقد المحروس

يضيف `tests/unit/automationActions.test.ts` سبع حالات بعزل كامل لمحمّل WorkOS
والإشعار وسياق منشأ الأتمتة ووقت ثابت:

1. نجاح إشعار النظام، رفضه، ورميه؛ وفي الحالتين الأخيرتين يبقى سجل النشاط بديلاً
   مرئياً وآمناً.
2. منع إنشاء مهمة متابعة ثانية للمفتاح نفسه، وربط المهمة الجديدة بالمهمة المصدر أو
   استعمال بديل المشروع/المسؤول الآمن عند غياب المصدر.
3. رفع الأولوية للمهام القابلة فقط داخل نطاق المشروع أو المهمة، بلا كتابة عندما لا
   توجد مهمة تستحق التغيير.
4. إغلاق المشروع مرة واحدة مع تسجيل النشاط، ونتائج صريحة للمشروع الغائب أو المغلق.
5. حصر الأرشفة بالمهام، ومعالجة الغياب والأرشفة المسبقة وكتابة وقت الأرشفة.
6. رفض الإجراء غير المعروف، ورد سبب الخطأ المعروف أو البديل الآمن للخطأ غير القياسي.
7. عدّ القواعد النشطة والطلبيات المتأخرة فقط، مع استثناء المسلّم والملغي واليوم الحالي.

لا يعتمد الاختبار على نتيجة «لم يرمِ»؛ بل يفحص محتوى الكتابات وترتيبها والحقول
المشتقة ورسائل كل نتيجة.
