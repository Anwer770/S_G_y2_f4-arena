# 23 — R58: ميزانية الإقلاع والتأجيل بعد الرسم الأول

**الإصدار:** 3.45.0

**التاريخ:** 2026-11-07

**النطاق:** تجزئة التطبيق في `AppRouter.tsx` و`UnifiedDashboard.tsx`، استيراد XLSX في `doctors.ts`، جدولة العمل غير الحرج في `deferredWork.ts`، وخط الحماية في `performance.test.mjs`.

## 1) القياس قبل الإصلاح والاختبار الأحمر

بُني الإصدار قبل R58 بلا اختبارات الدفعة. مورد JavaScript الابتدائي كان `index-5UVmK-HT.js` بحجم **2,405,203 B (2348.83 KiB)**، بينما كانت حزمة `vendor-react` **1 B** فقط؛ أي أن React لم يُفصل فعلياً، وكانت حزم XLSX والرسوم ضمن تحميل الإقلاع/`modulepreload`.

أُضيف `src/utils/deferredWork.ts` إلى `coverage.include` وإلى خط أساس H16 **قبل** كتابة اختباره؛ انتقل المقام من **48 إلى 49 ملفاً**. مرّت الوظيفة القائمة (**35 ملف اختبار / 711 حالة**) لكن بوابة التغطية فشلت لأن الملف الجديد كان **0%**. هذه هي الفجوة المقصودة المثبتة: لا ملف أُخرج من المقام لتمرير النسبة.

ثم أثبت الاختبار الأحمر/بوابة artifact أن المورد الابتدائي يتجاوز سقف **1,450,000 B** وأن فصل React وتحميل XLSX/Recharts المبكر غير صالحين. لا تعتمد البوابة على حجم gzip ولا على تخمين المصدر: تقرأ `dist/index.html` وملف البداية الذي سيطلبه المتصفح فعلاً بعد `npm run build`.

## 2) الإصلاح المحمي

| المسار | الحماية المضافة |
| --- | --- |
| `src/app/router/AppRouter.tsx` | حُوّلت جذور التبويبات الثانوية إلى `React.lazy` تحت `Suspense`. تبقى الشاشات التي زارها المستخدم في Keep-Alive، لكن لا توجد قائمة `allTabs` تسخّن 13 وحدة فور الإقلاع. |
| `src/components/dashboard/UnifiedDashboard.tsx` | دفتر السجل والرسوم ومحرر الملاحظات تحميلٌ كسول؛ الرسوم لا يبدأ طلبها حتى `deferNonCriticalWork` بعد الرسم الأول/وقت الخمول. |
| `src/utils/doctors.ts` | `xlsx` و`xlsxSafe` لا يُستوردان إلا عند التصدير أو اختيار ملف للاستيراد. |
| `vite.config.ts` | `manualChunks(id)` يصنّف معرفات `node_modules` الفعلية: React/ReactDOM/scheduler في `vendor-react`، وXLSX والرسوم وأيقونات Lucide منفصلة. |
| `src/utils/deferredWork.ts` | API صغير قابل للإلغاء: لا عمل في SSR، مهلة بعد paint، ثم `requestIdleCallback` عند توفره مع fallback آمن وإلغاء للمؤقت/وقت الخمول. |
| `tools/regression/performance.test.mjs` | سقف artifact **≤ 1,450,000 B**، يرفض `vendor-react` الفارغ، ورفض preload لـXLSX/الرسوم أو عودة pre-warm الشامل. وهو ضمن `verify` وCI بعد build. |

الـartifact الأخضر المقاس: `index-Cek7sGM8.js` **622,428 B (607.84 KiB)** و`vendor-react-CqDke1vM.js` **223.65 kB (218.41 KiB في البوابة)**. يوجد `modulepreload` اثنان فقط: React والأيقونات؛ `vendor-xlsx` و`vendor-charts` ليسا preload، ولا يُطلبان قبل فعل المستخدم.
