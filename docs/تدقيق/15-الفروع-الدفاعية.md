## 3) ما أُزيل (كود ميت مقيس)

```ts
// ProductRepository — كان:
const old = this.getById(id) || this.findBySubId(id);
// صار:
const old = this.getById(id);
```

`getById` في `BaseRepository` يطابق **`id` أو `subId`** (مقيس في R48)، فالسقوط إلى `findBySubId` لا يمكن أن يُنفَّذ: أي سجلّ يجده `findBySubId` يجده `getById` أولاً. حذف السطرين أزال **4 أذرع** من المقام (اثنتان منها كانتا غير مغطّاة) بلا أي تغيير سلوكي — والحالة القائمة «`getById` يطابق `id` أو `subId`» هي الدليل.
